White Matter Plasticity Following Cataract Surgery in Congenitally Blind Patients

Authors: Caterina A. Pedersini, Nathaniel P. Miller, Tapan Gandhi, Sharon Gilad-Gutnick, Vidur Mahajan, Pawan Sinha, Bas Rokers


This repository contains the analysis scripts, the behavioral data for both visual acuity and face discrimination task and the structural measures (FA/MD) extracted from each tract for each patient and control. 


All the analysis codes are provided as Matlab scripts and are located in the 'code' folder

The scripts S02-S05 use the following dependencies:
- Bioinformatics Toolbox of Matlab, to perform the FDR correction
- MediationToolbox-master: https://github.com/canlab/MediationToolbox
- CanlabCore: https://github.com/canlab/CanlabCore
